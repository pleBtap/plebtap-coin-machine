# Contributing to Plebtap Coin Machine

Thanks for your interest in contributing! 🚀

## How to Contribute

### Reporting Issues

Found a bug or have a suggestion? Open an issue with:
- Clear description of the problem or idea
- FreeCAD version (if applicable)
- Photos or screenshots if helpful

### Pull Requests

1. Fork the repository
2. Create a branch: `git checkout -b feature/your-feature-name`
3. Make your changes
4. Test in FreeCAD (open/save/export works correctly)
5. Commit with clear messages
6. Push and open a Pull Request

### What We're Looking For

- ✅ Improved dispensing mechanism
- ✅ Alternative payment integrations
- ✅ Better ZapBox mounting options
- ✅ Spare parts or alternative designs
- ✅ Documentation improvements
- ✅ Assembly instructions
- ✅ Photos and videos of builds
- ✅ BOM optimizations

### Design Guidelines

- Keep the design modular and serviceable
- Design for 3D-printability (minimal supports)
- Maintain parametric freedom (avoid hard-coded dimensions)
- Document any new parameters in the FreeCAD spreadsheet
- Consider alternative manufacturing methods (laser cut, CNC)

## Code of Conduct

Be respectful and constructive. We're all here to build cool stuff.

## Questions?

Open a discussion or reach out via the repository's communication channels.
